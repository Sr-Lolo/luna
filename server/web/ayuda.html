¿Qué es Luna?

Luna es un sistema de control remoto que convierte tu teléfono móvil en un teclado inalámbrico extendido para tu PC con Windows. A diferencia de soluciones genéricas (como aplicaciones de control remoto tradicionales), Luna procesa cada pulsación de tecla de forma local en el ordenador a través de un servidor FastAPI, ofreciendo una latencia prácticamente imperceptible independientemente de la velocidad de tu red Wi-Fi.

Arquitectura

  1. El móvil envía paquetes WebSocket binarios (KeyCommand o SliderCommand) al servidor en el PC.
  2. El servidor FastAPI recibe el paquete y lo deserializa mediante el protocolo interno (protocol.py).
  3. El keyboard_engine traduce el comando a una secuencia de eventos Win32 (SendInput, keybd_event).
  4. La tecla se ejecuta en la ventana activa del escritorio como si hubieras presionado físicamente el teclado.

Todo el pipeline móvil → PC ocurre en milisegundos. El audio local (MCI) y los sliders (volumen/brillo/scroll) se controlan mediante llamadas directas a Win32 API y ctypes, sin depender de servicios externos.

Casos de uso

  • Edición de video / audio: Atajos de teclado complejos (Ctrl+Shift+S, Alt+F4, etc.) sin levantarte del sillón.
  • Gaming: Teclas programables para MMOs, binds rápidos en shooters, o macros combinadas.
  • Streaming (OBS): Cambia escenas, silencia micrófono, lanza alertas con un solo toque desde el móvil.
  • Productividad: Perfiles específicos para Photoshop, VS Code, navegador, etc. con auto-cambio automático de perfil.

Conexión Móvil a PC

Para que el móvil y el PC se comuniquen, ambos deben estar conectados a la misma red Wi-Fi local. Luna no usa Internet en ningún momento del intercambio de teclas; todo el tráfico es interno (LAN).

Paso a paso

  1. Ejecuta Luna.exe en tu PC con Windows. Se abrirá una ventana con un spinner de carga; en segundo plano se inicia el servidor HTTP/WebSocket en el puerto 9120.
  2. Espera a que la interfaz cargue (verás el panel de control con el logo de Luna).
  3. En tu móvil, abre un navegador (Chrome, Firefox, Edge) o la APK de Luna.

Método A: Escáner QR (recomendado)

En la barra de estado del PC verás un botón con icono de QR [Escanear QR]. Pulsa ese botón y escanea el código con la cámara de tu móvil. El QR codifica la dirección http://{ip}:9120 y te llevará directo a la interfaz.

Método B: Manual

Si tu móvil no tiene cámara o el QR no funciona, escribe directamente en el navegador:

http://192.168.x.x:9120

Reemplaza 192.168.x.x por la IP local de tu PC. Puedes verla en la ventana de Luna o abriendo cmd → ipconfig y buscando la Dirección IPv4 de tu adaptador de red activo.

Cortafuegos (Firewall de Windows)

Si el móvil no conecta, es posible que el firewall esté bloqueando el puerto 9120. Abre el Panel de Control → Firewall de Windows → Permitir una aplicación o característica a través del firewall y asegúrate de que Luna.exe (o Python) tenga permisos en redes privadas. También puedes desactivar temporalmente el firewall para confirmar.

Red pública vs privada

Windows clasifica las redes Wi-Fi como "Públicas" o "Privadas". En redes públicas (cafés, bibliotecas) el firewall bloquea la comunicación entre dispositivos por defecto. Cambia la red a Privada en Configuración → Wi-Fi → Propiedades de la red.

Perfiles

Un perfil es un conjunto de botones (atajos) agrupados bajo un nombre, pensado para un contexto o aplicación específica. Por ejemplo, puedes tener un perfil "Photoshop" con teclas para pinceles y capas, otro "OBS" para cambiar escenas, y otro "Navegador" para pestañas y marcadores.

Crear un perfil

  1. En el panel principal, haz clic en el botón "+" que aparece junto a los chips de perfil.
  2. Ingresa un nombre único (máx. 20 caracteres).
  3. El nuevo perfil se crea con una cuadrícula vacía de 4×4 (16 botones).

Editar un perfil

La edición se realiza desde el Panel de control (/dashboard). Allí puedes:

  • Reordenar botones arrastrándolos a otra posición.
  • Editar un botón haciendo clic en él → se abre el editor con todos los campos (label, keyCode, modificadores, icono, sonido).
  • Vaciar un botón con el botón "Restaurar perfil".
  • Borrar el perfil (no se puede borrar "default").

Cambiar entre perfiles

En la interfaz principal, los perfiles aparecen como chips (páldoras) horizontales. Toca uno para activarlo. El perfil activo se marca con el color de acento (cian). También puedes cambiar de perfil desde el móvil.

Editor de Teclas

Cada botón de la cuadrícula representa un atajo de teclado o una acción. Al hacer clic en un botón desde el panel de control se abre el editor con los siguientes campos:

Label Etiqueta

Texto visible que se muestra en el botón. Máximo 8 caracteres para que no se desborde. Ejemplos: "Guardar", "Copiar", "SS".

KeyCode y Modificadores Atajo

Define qué tecla se presiona y con qué modificadores (Ctrl, Alt, Shift, Win).

  • KeyCode: Código numérico de la tecla según la tabla de códigos virtuales de Windows (Virtual-Key Codes). Puedes escribir directamente el número (ej. 83 = tecla S) o seleccionar desde el menú desplegable.
  • Modificadores: Selecciona uno o varios (Ctrl, Alt, Shift, Win). El valor se almacena como un bitmask que el servidor interpreta para generar la combinación exacta. Ejemplo: Ctrl + Shift + S se representa como KeyCode 83 con modificadores Ctrl|Shift.

Para teclas sin modificadores, el APK usa el comportamiento multi-touch + hold: mantén presionado para hold, toca rápido para pulsación única. Las teclas con modificadores siempre se ejecutan al tocar (tap).

Iconos Imágenes

Puedes asignar una imagen PNG, JPG o GIF (máx. 5 MB) para que aparezca dentro del botón. Los iconos se suben al servidor mediante el endpoint /api/upload-icon y se almacenan en la carpeta custom_icons del directorio de datos. Un icono bien elegido acelera el reconocimiento visual del atajo.

Sonidos MCI Engine

Luna puede reproducir un archivo de audio local (WAV o MP3) en el PC cuando presionas un botón. Esto usa el motor MCI (Media Control Interface) de Windows a través de ctypes.windll.winmm.mciSendStringW.

  • Multicapa: Cada sonido se reproduce en un canal independiente (alias luna_0 a luna_15). Puedes superponer hasta 16 sonidos simultáneamente sin que se corten entre sí.
  • Sin bloquear: La reproducción se lanza en un hilo separado (daemon=True), por lo que no interfiere con la recepción de comandos.

Consejo: sonidos de feedback

Asigna un sonido corto (ej. click.wav) a los botones críticos para tener confirmación auditiva de que la tecla se ejecutó. Esto es especialmente útil cuando el móvil está fuera de tu campo de visión.

Controles Avanzados

Sliders (Deslizadores Virtuales)

Luna incluye un slider táctil que puedes configurar para controlar diferentes parámetros del sistema. Al activar el modo Sliders (icono de sliders en la barra de modo), la cuadrícula de teclas se reemplaza por un control deslizante horizontal.

  • Volumen del sistema: Ajusta el volumen maestro de Windows (0-100%). Usa la API win32api para modificar el nivel del mixer de audio.
  • Brillo de pantalla: Controla el brillo del monitor mediante WMI (clase WmiMonitorBrightnessMethods). Solo funciona en monitores internos (portátiles).
  • Scroll horizontal: Emula eventos de rueda de desplazamiento horizontal (WM_MOUSEHWHEEL).
  • Scroll vertical: Emula la rueda del ratón estándar.

Puedes cambiar la función del slider desde el menú de selección que aparece en la parte superior del panel de sliders.

Hold (Tecla Mantenida)

El comportamiento Hold permite mantener una tecla presionada de forma continuada sin tener que sostener el dedo sobre el botón. Es útil para:

  • Desplazamiento continuo (flechas arriba/abajo).
  • Repetición de caracteres (backspace, espacio).
  • Juegos que requieren mantener presionada una tecla (acelerar, caminar).

En el APK, las teclas sin modificadores usan multi-touch + hold: toca rápido para pulsación única, mantén presionado para activar hold. Un indicador visual en el botón muestra si el hold está activo.

Auto-switch Cambio Inteligente

El auto-switch permite que Luna detecte automáticamente qué ventana está activa en tu PC y cambie el perfil del móvil al correspondiente, sin que tengas que tocarlo.

Cómo funciona

El componente WindowTracker ejecuta un bucle en segundo plano que consulta la ventana activa del escritorio cada 500 ms mediante la API GetForegroundWindow de Win32. Cuando detecta que el título o el ejecutable de la ventana activa coincide con un perfil configurado, envía un mensaje switch_profile a través del WebSocket al móvil.

Configuración

En el panel de control (/dashboard), puedes asociar un perfil a un ejecutable específico:

  1. Abre la sección de Auto-switch.
  2. Selecciona el perfil que quieres asignar.
  3. Busca el ejecutable de la aplicación (ej. photoshop.exe, code.exe, chrome.exe).
  4. Guarda la configuración.

Cuando el foco cambie a esa aplicación, el móvil cambiará automáticamente al perfil que le asignaste. Si la ventana activa no coincide con ningún perfil configurado, se mantiene el perfil actual.

Rendimiento

La consulta cada 500 ms es ligera (una llamada a GetForegroundWindow + lectura del título). No afecta al rendimiento del sistema ni al consumo de batería. Cuando no hay ningún móvil conectado, el tracker se pausa automáticamente.

APK vs Web

Luna se puede usar desde cualquier navegador moderno en el móvil, pero la APK de Luna ofrece ventajas significativas para el uso diario. Aquí tienes una comparación detallada:

APK de Luna (Recomendada)

  • Pantalla completa: Sin barra de direcciones, sin chrome del navegador. La UI ocupa todo el espacio disponible.
  • Wake lock: La pantalla del móvil no se apaga mientras usas Luna. No necesitas tocar la pantalla cada N segundos para mantenerla encendida.
  • Escáner QR nativo: Escanea el código QR directamente desde la app, sin aplicaciones de terceros.
  • Navegación pulida: El botón de retroceso de Android se integra con la UI, permitiendo ocultar/mostrar la interfaz sin recargar.
  • Actualizaciones automáticas: La APK verifica periódicamente si hay una nueva versión en GitHub y te ofrece descargarla e instalarla con un solo clic.

Versión Web (Navegador)

  • Sin instalación: Abres el navegador, escribes la URL y ya estás usando Luna. Ideal para una prueba rápida o si usas Luna esporádicamente.
  • Cross-platform: Funciona en iOS, Android, o cualquier dispositivo con un navegador moderno.
  • Limitaciones: La pantalla se apaga por el timeout del sistema, la barra de direcciones ocupa espacio valioso, y no hay escáner QR integrado.

Recomendación: Usa la versión web para probar Luna los primeros minutos. Si te gusta, instala la APK para una experiencia mucho más fluida y profesional. Puedes descargarla desde sr-lolo.github.io/luna.

FAQ Solución de problemas

¿Por qué no conecta mi móvil al PC?▼

Las causas más comunes son:

  • Firewall bloqueando el puerto 9120: Asegúrate de que Luna.exe o Python tengan permiso en redes privadas desde el Firewall de Windows.
  • Red pública: Windows bloquea la comunicación entre dispositivos en redes públicas. Cambia la red a "Privada" en Configuración → Wi-Fi → Propiedades.
  • Misma red: Verifica que ambos dispositivos estén conectados al mismo router y a la misma banda (2.4 GHz o 5 GHz). Algunos routers aíslan clientes en la banda de 5 GHz.
  • IP incorrecta: Revisa la IP que muestra la ventana de Luna. Si cambia con frecuencia, configura una IP fija en tu PC desde el router o desde Propiedades de red.

Si todo lo anterior está correcto, prueba acceder desde el navegador del PC a http://127.0.0.1:9120. Si no carga, el servidor no se inició correctamente.

¿Por qué no se escucha el sonido al presionar un botón?▼

El sonido se reproduce en el PC, no en el móvil. Revisa lo siguiente:

  • Archivo de audio: Asegúrate de que el archivo WAV o MP3 se subió correctamente al servidor (desde el editor de teclas en el panel de control).
  • Formato soportado: Solo WAV y MP3. El servidor rechaza otros formatos con un error 400.
  • Bocinas del PC: Verifica que el volumen del PC no esté en silencio o demasiado bajo.
  • MCI ocupado: El motor MCI tiene 16 canales disponibles. Si superas ese límite simultáneo, los sonidos adicionales se ignoran silenciosamente.
¿Cómo minimizo Luna sin cerrarlo?▼

Luna puede ejecutarse en segundo plano (bandeja del sistema) mientras el servidor sigue activo para el móvil.

  1. Presiona la X de la ventana de Luna.
  2. En el diálogo que aparece, selecciona "Segundo plano".
  3. La ventana se oculta y aparece un icono en la bandeja del sistema (junto al reloj de Windows).
  4. Para restaurar la ventana, haz doble clic en el icono de la bandeja.
  5. Para cerrar Luna completamente, haz clic derecho en el icono y selecciona "Salir", o presiona la X y elige "Cerrar completamente".
Los perfiles no aparecen o no se guardan los cambios▼

La configuración de perfiles se almacena en un archivo JSON en el directorio de datos de Luna. Si los cambios no persisten:

  • Permisos de escritura: Asegúrate de que el usuario de Windows tenga permisos de escritura en el directorio donde está instalado Luna.
  • Archivo corrupto: Si el JSON se dañó, puedes restaurar la configuración por defecto desde el panel de control (botón "Restaurar perfil").
  • Doble instancia: Luna bloquea la ejecución de múltiples instancias. Si dos instancias escriben simultáneamente, los datos pueden sobrescribirse.
