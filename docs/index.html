📥 Descargar APK
🔒 Seguro — Descarga directa desde GitHub con HTTPS
📱 Tamaño: ~200 KB · Requiere: Android 8.0+
⚠️ Chrome puede bloquear la descarga

Si Chrome muestra "Archivo dañino bloqueado":
1. Toca el icono de descarga ⬇ en la barra superior
2. Busca "Luna.apk" y toca "Conservar"
3. Toca "Conservar de todos modos"

O usa Firefox o Samsung Internet (descargan sin bloqueo).
📲 Funciona con Luna.exe en tu PC

Después de instalar la APK, abre Luna.exe en tu PC y escanea el código QR que aparece en la pantalla para conectar automáticamente.
