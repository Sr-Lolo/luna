POLÍTICA DE PRIVACIDAD

LunaDeck

Última actualización: 7 de julio de 2026

1. INFORMACIÓN GENERAL

LunaDeck ("la Aplicación") es una herramienta que permite controlar un PC con Windows desde un dispositivo móvil Android mediante conexión WebSocket en la red local. La Aplicación no requiere registro de cuentas ni recopila información personal identificable a través de servidores externos.

2. DATOS QUE NO RECOPILAMOS

LunaDeck no recopila, almacena ni transmite a terceros los siguientes datos:

  • Nombre, correo electrónico, número de teléfono o dirección
  • Contenido de teclas, macros o comandos enviados desde el móvil al PC
  • Archivos, documentos o capturas de pantalla del usuario
  • Credenciales de acceso o contraseñas
  • Datos de ubicación geográfica

3. DATOS DE CONEXIÓN LOCAL

Toda la comunicación entre el dispositivo móvil y el PC ocurre exclusivamente dentro de la red local del usuario (LAN/WiFi). No se utiliza ningún servidor en la nube para el procesamiento de comandos. El código QR generado para la conexión contiene únicamente la dirección IP local y el puerto del PC, y no se comparte con servidores externos.

4. PUBLICIDAD

La versión gratuita de LunaDeck puede mostrar anuncios proporcionados por Adsterra (highperformanceformat.com). Estos anuncios pueden utilizar cookies y tecnologías similares para mostrar publicidad basada en intereses. El manejo de datos por parte de Adsterra se rige por su propia política de privacidad disponible en https://adsterra.com/privacy/.

5. COMPRAS INTEGRADAS (LunaDeck Pro)

Las compras realizadas dentro de la Aplicación (LunaDeck Pro) se procesan a través de la Tienda Microsoft. Microsoft puede recopilar información necesaria para procesar el pago. LunaDeck no recibe ni almacena información de pago del usuario.

6. ACTUALIZACIONES AUTOMÁTICAS

La versión Android de LunaDeck consulta periódicamente un archivo JSON alojado en GitHub Pages (sr-lolo.github.io/luna) para verificar la disponibilidad de actualizaciones. Esta consulta no transmite ningún dato del usuario.

7. SEGURIDAD

LunaDeck implementa medidas de seguridad razonables para proteger la comunicación local, incluyendo bloqueo por archivo PID para evitar instancias duplicadas. Sin embargo, al ser una herramienta de control remoto, se recomienda su uso exclusivamente en redes de confianza.

8. ENLACES A TERCEROS

La Aplicación puede contener enlaces a sitios web de terceros (como Adsterra o GitHub Pages). LunaDeck no se responsabiliza por las prácticas de privacidad de dichos terceros.

9. CONTACTO

Para cualquier consulta sobre esta política de privacidad, puede contactar al desarrollador a través del repositorio oficial del proyecto.

10. CAMBIOS EN ESTA POLÍTICA

Nos reservamos el derecho de actualizar esta política de privacidad en cualquier momento. Los cambios serán comunicados a través de la página oficial de la Aplicación.
